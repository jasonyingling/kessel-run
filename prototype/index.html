The route

Eight stages, in order, with a time budget each

Stage 0 is dashed because Research is optional — a run can start at Anchor. The times are the targets the skills themselves set, and they add up to the ~35 minutes quoted for a full pipeline excluding Research.

  1. STAGE 0 Research 20–30 min · optional Research brief with gaps & angles
  2. STAGE 1 Anchor ~3 min Topic, audience, goal, framing
  3. STAGE 2 Ideation ~5 min Thesis, points, stories, evidence
  4. STAGE 3 Hook ~3 min Hook + bridge, variants scored
  5. STAGE 4 Architecture ~5 min Beat map, section by section
  6. STAGE 5 Draft ~8 min Section drafts, one at a time
  7. STAGE 6 Personalize ~3 min Authenticity audit + prompts
  8. STAGE 7 Polish ~4 min Scorecard across 7 dimensions

Off the route — no fixed position in the run

Review Audit a published piece. 10–15 min per piece.
Repurpose Adapt a finished piece to another format. 5–10 min per format.
Analyze Post-publish performance, feeding the next run. 10–15 min.

The pipeline

ResearchStage 0
Map what already exists and where the gaps are, before committing to an angle.
“research this” · “what’s out there”
AnchorStage 1
Pin the topic, audience, goal and framing before a word gets written.
“I have an idea” · “help me plan”
IdeationStage 2
Develop the thesis into points, stories and the evidence behind each.
“help me develop” · “what angles”
HookStage 3
Write the opening and the bridge into the piece. Several variants, scored.
“I need a hook” · “how should I open”
ArchitectureStage 4
Lay out the beat map, section by section, with energy flow planned.
“help me outline” · “what structure”
DraftStage 5
Write it one section at a time, editing as you go.
“let’s start writing” · “draft this”
PersonalizeStage 6
Audit for authenticity and ground the general claims in specifics.
“too generic” · “make it sound like me”
PolishStage 7
Final quality check against seven dimensions, with a fix for each.
“is this ready” · “final review”

What happens on send

      
How a pinned skill reaches the agent

      
The numbering here is a real sequence — each step depends on the one above
      it, and the third is where the design earns its keep.

    


    

      

        
01

        

          
The rail sets the pin

          
Choosing a stage stores its skill name in client state. Nothing is sent yet.

        

      

      

        
02

        

          
The message carries it

          
The chat transport posts to /api/kessel-run/projects/[id]/chat with the pinned skill in the body.

        

      

      

        
03

        

          
The body is resolved at send time, not at construction

          
The transport’s body takes a function. A plain object would freeze the pin at its first value and every later message would carry a stale one — the single most likely way this feature breaks.

        

      

      

        
04

        

          
The route puts it in request context

          
The agent’s dynamic skills resolver reads requestContext and returns that skill first.

        

      

      

        
05

        

          
The agent may still reach past the pin

          
Pinning is a default, not a cage. Anchor can hand off to Ideation mid-conversation, and the tool call shows in the transcript so the user sees which skill answered.

        

      

      

        
06

        

          
Artifacts refresh when the turn ends

          
On finish, the workspace refetches project state, so the rail and the artifact panel reflect what the agent actually wrote to working memory.
