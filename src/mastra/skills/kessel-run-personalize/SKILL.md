# Kessel Run — Stage 6: Personalize

Audit the draft against the selected editorial voice. The target may be a publication or a publication plus author overlay; it is not automatically the account owner's natural voice.

## Workspace context

Before starting, read [the shared workspace contract](references/workspace.md) to locate the selected publication, exact voice versions, output and sources, preserve existing notes, and provide a resumable handoff when files are unavailable.

Use the output's selected publication voice and optional author overlay at their pinned versions; keep parent editorial requirements distinct from author differences. Approved sparse profiles or explicit supplied preferences are sufficient. Do not default to the account owner's voice. Ask only for unresolved choices after reading accessible state. Preserve human edits, exact machine drafts and accepted finals as described in the workspace contract.

Use the Brief/output's mode: guided by default, fast when requested. Reuse supplied work and skip unnecessary stages; numbered stages describe available methods, not mandatory gates. All factual and personal claims, including hooks, transitions and endings, need source support from interviews, notes, testing records or attributed research. Profile examples supply style, not new facts. Claim-free connective language is allowed. Use specific placeholders for missing facts and report gaps without blocking supported writing. A confident voice never licenses invented use, tests, results or certainty, or attributing an unexpressed opinion to the author. Supported editorial analysis and provisional recommendations may be proposed with reasoning; label inference rather than presenting it as observed fact. Keep scorecards outside prose; acceptance is not fact verification or publishing authorization.

## Review the draft

Read the actual draft, pinned profiles, brief and necessary sources. A fast draft is valid input; prior section approvals are not required. Preserve the exact machine draft before editing. Review paragraphs for:

- **Voice fit:** tone, rhythm, vocabulary, Use/Avoid rules, format variations and evidenced signature devices. Keep required parent rules and author differences distinguishable. Sparse approved profiles are usable; do not penalize unspecified dimensions.
- **Specificity and support:** identify unsupported generalizations, missing attribution and factual placeholders. Research-based explanation is valid; first-person stories are optional. Claim-free framing can remain when it helps the reader.
- **Useful editorial changes:** tighten formulaic transitions, remove repetitive phrasing, sharpen a supported observation, or request a particular missing detail when it would materially improve the piece.

If scores help the author, use a 1–5 voice-fit scale with concrete examples of the relevant profile rule. Scores are diagnostic judgments, not evidence of accuracy. Avoid personal/informed content ratios or compulsory anecdotes. A sports analysis or product review can be authentic without a personal story.

## Collaborate and revise

In guided mode present the few most consequential passages and suggested changes, then incorporate the author's decisions. Ask one focused content question if needed, such as which actual test supports a verdict. In fast mode perform the requested revision pass and report substantive changes and unresolved gaps together.

Do not attribute an unexpressed opinion to the author, invent experience or remove factual uncertainty just to sound confident. A requested editorial judgment can be proposed from evidence with its reasoning and limitations; distinguish that inference from an observed result. Do not turn notes about another author's use into the selected author's experience. If a required profile rule conflicts with an explicit current edit, surface the conflict and ask only for the consequential decision. Apply piece-specific edits locally; propose reusable profile changes separately rather than silently learning them as rules.

Return clean revised prose separately from the review notes, with a link or filename for the retained previous draft and unresolved claims. Keep the original output and other profiles untouched. Name Polish as a possible next action when the draft needs final editorial review; do not mark it accepted or publish it.
