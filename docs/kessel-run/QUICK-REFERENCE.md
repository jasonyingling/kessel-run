# Kessel Run quick reference

Start with `kessel-run-start` to begin, resume or find the next useful action. Supply the workspace root/home note or a self-contained handoff. Existing publication, output and profile selections should not be asked again.

| You need | Skill | Result |
| --- | --- | --- |
| Begin or continue | kessel-run-start | Loaded selections, sources, progress and next action |
| Establish intended voice | kessel-run-voice | Publication profile and optional author differences; sparse is valid |
| Gather missing material | kessel-run-interview | Verbatim answers with a separate material inventory |
| Find evidence | kessel-run-research | Attributed findings and honest coverage limits |
| Sharpen direction | kessel-run-anchor | Topic, audience, outcome and framing |
| Develop substance | kessel-run-ideation | Supported points proportional to format |
| Improve the opening | kessel-run-hook | Supported hook and bridge |
| Organize the piece | kessel-run-architecture | Lightweight outline or fuller beat map |
| Write prose | kessel-run-draft | Guided section or complete fast draft |
| Match a profile | kessel-run-personalize | Voice revision preserving claims and human edits |
| Edit before acceptance | kessel-run-polish | Revised prose and separate scorecard |
| Adapt a piece | kessel-run-repurpose | Independent outputs with explicit target voices |
| Check old content | kessel-run-review | Verified findings or named freshness gaps |
| Learn from accepted edits | [kessel-run-lessons](../kessel-run-lessons.md) | Confirm publication/author voice lessons from exact draft and final |
| Assess performance | kessel-run-analyze | Evidence-based, profile-scoped lesson proposals |

Numbered methods remain Research0, Anchor1, Ideation2, Hook3, Architecture4, Draft5, Personalize6 and Polish7. The other seven skills are standalone (15 total). None requires running every earlier method.

## Useful requests

- “Resume this Brief using its saved Jason profile and parent version.”
- “Write a full fast review from these notes. I have no personal testing experience.”
- “Use guided mode; let me edit each section.”
- “Use the approved sparse profile for The Greatest Ever Reviews; no archive needed.”
- “Turn this into two independent outputs with these target profiles. Preserve the original.”
- “No file access: give me the full Markdown handoff, including actual rules, inputs and current draft.”

## Working rules

Read selected state and needed sources, not whole archives. Voice controls style; sources support claims; presets define format. Keep parent editorial requirements and author differences distinct. Existing version pins must resolve to actual retained rules. Missing facts use specific placeholders, including in hooks and endings. Research and Review report unavailable verification rather than inventing searches.

Capture machine drafts before edits, preserve human changes and record an accepted final only after actual acceptance. Keep scorecards separate. No numerical personal-content ratio or mandatory anecdote applies. A destination label and accepted draft do not authorize publishing.
